# PROJECT KNOWLEDGE BASE

## Overview

DocWise is an enterprise developer knowledge workflow agent: technical-document RAG, troubleshooting tools, traces, and evaluation.

## Stack

- Python 3.11 package with FastAPI, SQLAlchemy async, Alembic, arq, Streamlit.
- PostgreSQL with pgvector, Redis, and MinIO for the local stack.
- DeepSeek-compatible chat and DashScope/Qwen embedding/rerank wrappers.
- Ruff and pytest are the quality gates.

## Important Paths

- `src/api/`: FastAPI app, dependencies, and routers.
- `src/document/`: parsers, chunking, embedding, and ingestion orchestration.
- `src/agent/`: LangGraph state, nodes, prompts, and tools.
- `src/retrieval/`: vector, keyword, hybrid, rerank, and metadata filters.
- `src/observability/`: traces, metrics, bad-case classification, eval runner.
- `src/frontend/`: Streamlit app and pages.
- `scripts/`: seed, ingest, fixture validation, export, and smoke scripts.
- `data/mock/` and `data/eval/`: required local fixtures.
- `data/raw/`: reproducible demo documents generated by `scripts.download_docs`.

## Guardrails

- Do not delete source tests, fixtures in `data/mock/` or `data/eval/`, env templates, migrations, or docs contracts.
- `.env` may contain secrets and must stay ignored.
- Use absolute `src.*` imports.
- Keep API, SSE, JSONB, and schema fields in `snake_case`.
- Do not log API keys, tokens, passwords, or full uploaded documents.

## Validation

```powershell
.\.venv\Scripts\python.exe -m scripts.validate_mock_data
.\.venv\Scripts\python.exe -m scripts.validate_eval_cases
.\.venv\Scripts\python.exe -m ruff check src tests scripts alembic
.\.venv\Scripts\python.exe -m pytest -q
```
